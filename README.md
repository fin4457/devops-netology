## Описание работы .gitignore для Terraform

Благодаря добавленному файлу конфигурации, Git будет автоматически игнорировать следующие файлы и каталоги при разработке с использованием Terraform:

* **Служебные каталоги (`.terraform/`):** Локальные папки, куда Terraform скачивает провайдеры и модули. Их не нужно хранить в репозитории, так как они инициализируются заново командой `terraform init`.
* **Файлы состояния (`*.tfstate`, `*.tfstate.*`):** В этих файлах хранится текущий статус вашей инфраструктуры. Они часто содержат чувствительные данные и постоянно меняются, поэтому их хранят в удаленных бэкендах (например, AWS S3), а не в Git.
* **Логи ошибок (`crash.log`):** Автоматически создаваемые отчеты о сбоях в работе утилиты.
* **Файлы с переменными (`*.tfvars`, `*.tfvars.json`):** Файлы, в которых описываются конкретные значения для конфигурации. В них часто находятся пароли, токены и приватные ключи, которые категорически нельзя пушить в публичный или приватный репозиторий.
* **Кастомные файлы перезаписи (`*override.tf`):** Локальные файлы, используемые разработчиками для временного переопределения параметров без изменения основного кода.
